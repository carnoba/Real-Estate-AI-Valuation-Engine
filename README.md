A professional-grade Machine Learning system designed for precision real estate valuation. This project achieves a **91% R² score** on the Ames Housing dataset by implementing an end-to-end pipeline featuring **3-Sigma data cleaning**, hyperparameter-tuned **XGBoost**, and an interactive Streamlit dashboard for stakeholders.

## 🚀 Project Overview

The **Real Estate AI Valuation Engine** is more than just a regression model. It’s a comprehensive decision-support system for real estate investors and agents, providing high-accuracy price predictions and clear interpretability of feature impacts (amenities, location, condition).

## ✨ Premium Features

- **Advanced Preprocessing**: Implements 3-Sigma outlier detection and robust feature engineering to handle sparse housing data.
- **God-Tier Performance**: Optimized XGBoost regressor delivering industry-leading accuracy (91% variance explained).
- **Interpretability Layer**: Uses SHAP-based analysis (or similar) to explain *why* a house is priced at a certain level.
- **Stakeholder Dashboard**: A clean, responsive Streamlit app enabling real-time valuation for any property configuration.
- **Professional Deliverables**: Includes a clean PDF presentation for high-level technical reviews.

## 🛠 Tech Stack

- **ML Frameworks**: XGBoost, Scikit-learn
- **Data Engineering**: Pandas, NumPy
- **Deployment**: Streamlit
- **Visualization**: Matplotlib, Seaborn

## ⚙️ Installation & Usage

1. **Clone the Repo**:
   ```bash
   git clone https://github.com/carnoba/Real-Estate-AI-Valuation-Engine.git
   ```
2. **Setup Environment**:
   ```bash
   pip install pandas xgboost scikit-learn streamlit matplotlib seaborn
   ```
3. **Launch the Engine**:
   Explore the modeling process in `amees housing/` or run the Streamlit dashboard scripts.
